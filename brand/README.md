# OsaBooks logo files

The OsaBooks wordmark: a ticked circle for the O, for books that check their
own work, then the rest of the name.

| File | Use it for |
|---|---|
| `osabooks-logo.svg` | The logo on white or light backgrounds. Scales to any size. |
| `osabooks-logo-white.svg` | The logo on navy or dark backgrounds. |
| `osabooks-mark.svg` | The ticked circle alone: icons, avatars, favicons. |
| `osabooks-logo-600/1200/2400.png` | The light-background logo where an SVG is not accepted. |
| `osabooks-logo-white-600/1200/2400.png` | The same, for dark backgrounds (transparent). |
| `osabooks-mark-64/180/512/1024.png` | The mark, square, transparent around the circle. |
| `social-preview.png` | GitHub's social preview (Settings, General, Social preview), 1280 x 640. |

## Colours

| | Light backgrounds | Dark backgrounds |
|---|---|---|
| Letters | `#0b2340` | `#ffffff` |
| Ring | `#0b3d69` | `#5aa9e6` |
| Tick | `#c25e1a` | `#f08a3c` |

## Lettering

The letters are outlines taken from Inter Bold (by Rasmus Andersson, under the
SIL Open Font License, which allows its use in a logo), so the files look the
same on every computer whatever fonts it has.

The name "OsaBooks" (earlier "NZOSA") and this logo identify the project. The code's licence does
not cover them: see the additional terms in [NOTICE](../NOTICE).
